## 📖 What It Does

Alert Escalation for Toxic Alcohol Osmolar Anion Gap
Triggers clinical alerts when scores cross critical thresholds,
escalates rapid score changes, and routes to specialist workflows.

Author: Dr. Abu Suraih Sakhri
License: MIT

Longitudinal Score Tracking for Toxic Alcohol Osmolar Anion Gap
Stores sequential assessments with date-stamped clinical parameters,
tracks score trajectory, and classifies trends (improving/stable/deteriorating).

Author: Dr. Abu Suraih Sakhri
License: MIT

## ⚙️ Key Capabilities & Algorithmic Modules

### 🔬 Core Algorithmic & Evaluation Engines

- **`Alert`**: A clinical alert triggered by score thresholds.
- **`AlertEscalationEngine`**: Manages clinical alert escalation for toxic alcohol scores.
- **`Assessment`**: A single scored assessment with clinical parameters.
- **`TrendResult`**: Result of trend analysis over a series of assessments.
- **`LongitudinalTracker`**: Tracks toxic alcohol osmolar anion gap scores over time.
- **`RiskTier`**: Defines a risk tier with clinical pathway.

## 🛡️ Security & Enterprise Architecture

* **Zero-PHI Outbound Interceptor:** Active AST and regex inspection blocking SSNs, MRNs, phone numbers, and patient identifiers.
* **Tamper-Evident HMAC-SHA256 Audit Trail:** Chained, cryptographically signed logs for every evaluation and state transition.
* **Air-Gapped LLM Reasoning Adapter:** Agnostic integration for local Ollama instances (`llama3`, `mistral`), Claude 3.5 Sonnet, GPT-4o, and deterministic test mocks.
* **Active Learning Bayesian Calibration:** Dynamic tracker updating worker reliability weights and monitoring Brier calibration drift.
* **FastAPI & Prometheus Telemetry:** Exposes OpenAPI 3.1 REST endpoints and operational Prometheus metrics (`/metrics`).
